# Tugas dan Projek PBKK 2026

Repository ini digunakan sebagai tempat penyimpanan hasil pengerjaan **tugas, program, latihan, dan projek** selama mengikuti mata kuliah **Pemrograman Berbasis Kerangka Kerja (PBKK)** tahun 2026.

Repository disusun agar setiap hasil pengerjaan dapat terdokumentasi dengan rapi, terstruktur, dan mudah diakses kembali. Di dalam repository ini terdapat beberapa **folder yang dikelompokkan berdasarkan pertemuan perkuliahan**. Setiap folder berisi tugas atau program yang dikerjakan pada pertemuan terkait, termasuk source code, dokumentasi, dan file pendukung lainnya jika diperlukan.

Struktur repository secara umum dapat berkembang seperti berikut:

```text
Tugas-dan-Projek-PBKK2026/
│
├── Pertemuan-1/
│   └── ...
│
├── Pertemuan-2/
│   ├── Hello-World/
│   ├── Sistem-Data-Mahasiswa/
│   └── ...
│
├── Pertemuan-3/
│   └── ...
│
├── Pertemuan-4/
│   └── ...
│
└── README.md
```

Setiap folder pertemuan dapat berisi satu atau lebih project sesuai dengan materi, latihan, maupun tugas yang diberikan pada perkuliahan tersebut. Dengan struktur ini, seluruh pekerjaan selama satu semester dapat tersimpan dalam satu repository tanpa kehilangan pengelompokan berdasarkan pertemuan.

Repository ini juga berfungsi sebagai dokumentasi proses pembelajaran, mulai dari program sederhana hingga project yang lebih kompleks. Setiap project dapat dilengkapi dengan penjelasan mengenai tujuan program, implementasi, fungsi-fungsi yang digunakan, serta hasil program.
